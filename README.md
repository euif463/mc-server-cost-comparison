## 决定开服体验的其实是三个数字

**单核主频**排在第一位。Minecraft 的主世界逻辑跑在单个主线程上，CPU 核心再多，主线程慢了照样卡。这也是为什么高主频的 i9、Ryzen 系列机型比核心数更多的老 Xeon 更适合开服。

**内存**决定你能装多少东西。纯净服和装了 200 个模组的整合包，对内存的胃口差好几倍。官方给的参考基准是：MOD 服按 50 个模组、视距 5 来估算。

**上行带宽**决定人数天花板，下行带宽基本不影响游戏体验。

还有一个容易被忽略的变量：版本。1.18+ 的消耗大约是 1.16+ 的两倍，是 1.12.2 的三倍。同一个玩家数量，你开 1.20 和开 1.12.2，需要的配置完全不是一档。

## 固定计费还是动态计费，这个问题值得算一遍

雨云游戏云同时提供两种计费模式，官方文档里的说明很具体：

**固定计费**就是传统月租，买什么规格付什么价，不额外收费，适合 24 小时在线的长期服。

**动态计费**是低基础月租 + 按 CPU 实际使用量日结。计费依据是"CPU 电量"，这个虚拟单位的基准线是 20% 使用率：低于 20% 视为不耗电，超出 20% 的部分才算额外消耗。系统每天还会按实例规格赠送一定基础电量。

这个模式适合作息集中的服务器。比如一班学生只在晚上和周末上线，服务器白天基本空转，动态计费能把这部分成本省下来。反过来，如果你的服常年有人在线、CPU 一直处在较高占用，动态计费算下来不一定便宜，固定计费反而更可控。

管理页里有一个开关叫「用余额结算电费」：打开后，电量用尽会自动用余额抵扣，次日结算，服务器继续跑；关闭后，电量用完就直接限制性能。不想开服开一半突然发现被限速，把它打开。

## 价格之外，这些地方会花钱

套餐价不是最终账单。开服前把这些隐性成本算进去，免得续费时觉得被坑：

- **独立公网 IP**：部分机型走 NAT 共享 IP，靠端口映射对外服务。需要独立 IP 或更高防护的 IP 要单独加购，价格按区域和防护等级差得比较多。
- **硬盘扩容**：不同区域单价不一样，大概在 0.65 元到 1 元每 GB 每月这个区间。模组服存档、备份文件会持续吃硬盘，提前留余量。
- **带宽加购**：部分游戏云 VPS 支持按档加带宽，5Mbps 一档对应固定加价。
- **流量包**：大带宽限流量机型用超流量后会限速到 5Mbps，可以购买流量包恢复高速。

1. 注册账号，在注册页填写优惠码或直接走专属链接，绑定手机/邮箱/微信，完成实名认证；
2. 进「云产品 → 游戏云」，购买或者用积分兑换一台游戏云；
3. 在管理页点「重装/切换游戏」，选游戏类型（Minecraft JAVA、基岩版等）、服务端核心和版本，执行操作；
4. 等 1~2 分钟安装完成，进入 MCSM 控制台；
5. 如果是离线服，打开 `server.properties`，把 `online-mode=true` 改成 `false`；正版服不用改；
6. 点开启实例，控制台刷出 `Done` 表示启动成功；
7. 回到雨云管理页，在「信息与监控 → NAT 端口映射管理」复制游戏端口对应的地址；
8. 打开游戏客户端，「多人游戏 → 添加服务器」，填地址进服。控制台输入 `op 玩家名` 可以给管理员权限。

想用自己的服务端核心（Paper、Purpur、Spigot、Fabric、Forge、整合包），在面板文件管理里上传，再改启动脚本里的 jar 文件名就行，格式是 `java -Xms内存 -Xmx内存 -jar 服务端名.jar`。

## 新手最容易翻车的几个点

**端口没映射就发给朋友**。NAT 机型的地址是 `IP:端口` 的形式，只复制 IP 进不去，端口号要带上。

**忘了关正版验证**。离线玩家进不来，先确认 `online-mode` 这一项。

**视距拉太高**。`view-distance` 和 `simulation-distance` 是性能开销最大的两个参数，人一多先把视距降下来，比升级 CPU 立竿见影。

**CPU 电量用超了**。动态计费机型如果没开「用余额结算电费」，电量耗尽会被限性能，表现为突然卡顿。开服前把开关设好。

**不备份**。开服半年攒下的存档，比重买一台服务器值钱。
